Word Document (.docx) Formatting Standard

Lecturers and teachers can write their questions directly inside a Microsoft Word document (.docx) and import them all at once. To ensure that our automated system can successfully read your file, your document must follow this simple structure:

Example Word Template 
Level 1:

1. នៅក្នុងកម្មវិធី Word តើ Tab មួយណាដែលត្រូវបានប្រើប្រាស់ដើម្បីកំណត់ Margins (គម្លាតរឹម)?
A). Design tab
B). Home tab
C). Layout tab
D). View tab
Answer: C

2. Shortcuts key Ctrl + Home is used to go to start of document.
A). True
B). False
Answer: A

Level 2:

3. What is the default port number of Apache HTTP Server?
Answer: 80

✅ Clean Formatting Checklist

  • ✔️ Question numbers: Must start with numbers followed by a separator (e.g. 1., 2)). Avoid making the numbers bold or italic.
  • ✔️ Choice letters: Prefix multiple-choice options with A)., B)., C)., D). (or A., B.).
  • ✔️ Correct Answer indicator: End every question with a line starting with Answer: followed by the correct choice letter (e.g. Answer: D).
  • ✔️ Difficulty Levels: Place Level 1: or Level 2: on its own line above the questions to group and tag them automatically.

🤖 AI-Assisted Formatting (Recommended)

If your Word document has messy formatting or does not match our system's structure, you do not need to rewrite it manually! You can copy our custom formatting prompt, paste it into Gemini, ChatGPT, or any AI tool along with your questions, and it will clean them up for you instantly.
